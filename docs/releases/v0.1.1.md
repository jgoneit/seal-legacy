# Harness v0.1.1

Language: English | [한국어](v0.1.1.ko.md)

## Highlights

v0.1.1 is a patch release of the Experimental Core. The Windows check runner attaches each check to a kill-on-close Job object so that background descendants left behind after a successful parent process exits cannot continue writing to Evidence logs.

The Codex Plugin is distributed under the name `harness`. After installation, select the plugin with `@harness` or explicitly invoke the bundled Skill with `$harness`.

## Compatibility

Core CLI commands and the JSON stdout contract remain compatible with v0.1.0. The Python distribution name remains `outcome-harness`, and the console command is `harness`.

## Known limits

This release verifies only the local consistency of stored Evidence. It does not provide current-source binding, cryptographic provenance, complete secret redaction, or control over how an Agent works. Processes that use intentional breakaway after Windows Job assignment are outside this boundary.

## Install

```bash
python3 -m pip install \
  "git+https://github.com/jgoneit/harness.git@v0.1.1"
```
