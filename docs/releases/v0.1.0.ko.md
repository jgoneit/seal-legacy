# Outcome Harness v0.1.0

Language: [English](v0.1.0.md) | 한국어

## Highlights

Outcome Harness v0.1.0은 Agent 작업 과정을 통제하지 않고, Task 변경과 검증 결과를
reviewable Evidence Run으로 남겨 evidence-based completion을 지원하는 첫
Experimental release다.

## Included

- Task snapshot과 Git baseline 기록
- scope 기반 변경 수집, argv 기반 check 실행, mechanical Evidence 저장
- Canonical Verdict validation, Run integrity validation, Run Evidence Manifest
- raw-byte digest와 `evidence_sha256` local consistency identifier
- portable verifier bundle, manual Verdict record/show, fail-closed completion
- stable exit code, wheel package, GitHub Actions CI

## Known Limitations

- current source binding을 지원하지 않는다. verify 뒤 source가 바뀌어도 `complete`는
  저장된 Run Evidence만 읽는다.
- `verify --base-ref`가 Task baseline을 Run 단위로 override할 수 있다.
- digest는 local consistency 확인일 뿐 remote trust anchor, signature, attestation,
  immutable storage가 아니다.
- 이 버전은 Experimental이며 tamper-proof, production enforcement, 또는 enterprise
  enforcement-ready를 주장하지 않는다.
- Multimodal Evidence와 external verifier adapter는 포함하지 않는다.

## Installation

Git tag가 발행된 뒤 다음 명령으로 설치할 수 있다.

```bash
python3 -m pip install \
  "git+https://github.com/jgoneit/harness.git@v0.1.0"
```

GitHub Release wheel asset은 Release가 실제로 생성된 뒤에만 사용한다. 이 문서는
사전에 asset URL을 고정하지 않는다.

## Verification

Release workflow는 `v0.1.0` tag push에서 contract sync, full unittest, wheel/sdist
build, `twine check`, clean wheel CLI/resource smoke test를 실행한 뒤에만 GitHub
Release와 wheel/sdist asset을 생성한다.
