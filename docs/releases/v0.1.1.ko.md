# Harness v0.1.1

Language: [English](v0.1.1.md) | 한국어

## Highlights

v0.1.1은 Experimental Core의 patch release다. Windows check runner는 각 check를
kill-on-close Job object에 연결해, 성공한 부모 process가 먼저 끝난 뒤에도 남은
background descendant가 Evidence log에 계속 쓰지 못하도록 정리한다.

Codex Plugin은 `harness` 이름으로 제공한다. 설치 뒤에는 `@harness`로 plugin을
선택하거나 `$harness`로 bundled Skill을 명시적으로 호출할 수 있다.

## Compatibility

Core CLI 명령과 JSON stdout 계약은 v0.1.0과 호환된다. Python distribution name은
계속 `outcome-harness`이고 console command는 `harness`다.

## Known limits

이 release는 저장된 Evidence의 local consistency만 검증한다. 현재 source binding,
cryptographic provenance, 완전한 secret redaction, Agent 작업 과정 제어를 제공하지
않는다. Windows Job assignment 뒤 intentional breakaway를 사용하는 process는 이
boundary 밖이다.

## Install

```bash
python3 -m pip install \
  "git+https://github.com/jgoneit/harness.git@v0.1.1"
```
